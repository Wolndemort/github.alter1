# ALTER: дополнительные кредиты

Доступен единый каталог для Telegram, mobile и web:

- 500 кредитов — 490 ₽;
- 1500 кредитов — 990 ₽;
- 3500 кредитов — 1990 ₽.

Покупка зачисляется на постоянный общий баланс аккаунта и суммируется с остатком. Пакеты не сгорают и не продлевают подписку. Любая подписка действует ровно 30 календарных дней; покупка пакета дату окончания не меняет.

Оплата создаётся через общий YooKassa backend (`/api/v1/credits/packs/create-payment`). Telegram использует `/buy_credits`; mobile и web используют те же API и общую учётную запись.
