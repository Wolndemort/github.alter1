# ALTER: план конкурирования с ChatGPT и Gemini

## Приоритет ближайшего релиза

1. Быстрый контур: короткий запрос сразу получает SSE, первый статус приходит до первого токена, затем идут `delta`, `done` или `cancelled`. Для поиска и внешних инструментов используется отдельный маршрут со статусом `searching`.
2. Сильный контур: дешёвая классификация выбирает быстрый ответ, планирование или reasoning-модель. Решение маршрутизатора должно измеряться отдельно от качества финального ответа.
3. Параллельные инструменты: независимые web/weather/calendar операции выполняются через `asyncio.gather` с таймаутом, отменой и явным результатом каждого инструмента.
4. Русский по умолчанию: современная разговорная лексика, сленг, голосовой ввод и локальные сценарии проверяются отдельным русским eval-набором.

## Фирменные сценарии

`Разложи мой день`, `Доведи дело до результата`, `Разберись, что я чувствую`, `Подготовь меня к разговору`, `Прими решение со мной`, `Собери всё по проекту`, `Верни меня к тому, что важно` должны быть не рекламными кнопками, а повторяемыми workflow с памятью, чек-листом, следующими действиями и возможностью остановки.

## Качество и доверие

Каждый релиз измеряем на реальных обезличенных сценариях: полезность, живость, память, фактическая точность, p50/p95 первого токена, стоимость, успех инструментов и повторный запрос «не то». В журнале ответа храним только безопасные метаданные: маршрут, статусы, длительности, инструменты и причину отмены — без ключей и полного текста запроса.

Пользователь должен видеть, использовался ли интернет, какие действия реально выполнены, что сохранено в памяти, и иметь приватный режим, полное удаление данных и журнал действий ALTER.

## Definition of Done

- backend и mobile tests;
- eval на русском и на сленге;
- p50/p95 latency dashboard;
- отмена на каждом внешнем вызове;
- ни один ответ не утверждает действие без подтверждённого результата;
- изменение не меняет биллинг без отдельного теста.
