# Физический Alter — расширяемый прототип

## Главная идея

Первый прототип — голосовой настольный Alter, но архитектура сразу закладывается расширяемой: позже добавляются камера, NFC, сервоприводы, голова, колёса, датчики и другие контроллеры без замены основного компьютера.

## Ядро

- Raspberry Pi 4 4 GB — достаточно для первого этапа и надолго.
- Raspberry Pi 5 8 GB — вариант с запасом для локального распознавания речи, камеры и компьютерного зрения.
- Raspberry Pi Zero 2 W для основного голосового устройства не брать.

Pi работает как Linux-компьютер и общается с существующим Alter API.

## Архитектура

```text
Микрофон / камера / файлы
          ↓
Raspberry Pi — ядро устройства
          ↓ Wi‑Fi / HTTPS
Alter API на VPS
          ↓
голосовой ответ и команды
          ↓
ESP32-контроллеры → свет, NFC, сервоприводы, моторы, датчики
```

Raspberry Pi не заменяется при каждом расширении. Каждому новому модулю можно выделить отдельный ESP32 или другой контроллер.

## Покупки для старта

1. Raspberry Pi 4 4 GB или Pi 5 8 GB.
2. Качественная microSD 64 GB A2.
3. Качественный блок питания USB‑C.
4. Радиатор/корпус с охлаждением.
5. USB-микрофон или ReSpeaker.
6. USB-колонка или небольшой динамик.
7. Кнопка запуска разговора.
8. RGB-кольцо или светодиоды для статусов.
9. ESP32 DevKit — контроллер будущих устройств.
10. 2–4 сервопривода SG90/MG90S.
11. Макетная плата и Dupont-провода.
12. Отдельное питание 5V для сервоприводов.
13. PCA9685 для управления несколькими сервоприводами.

Сервоприводы можно купить заранее, но подключать их сначала не обязательно.

## Будущие контроллеры

- ESP32 #1: кнопки, NFC, свет и простые датчики.
- ESP32 #2: сервоприводы и движения головы.
- ESP32 #3: моторы и колёса.
- Raspberry Pi: аудио, камера, файлы, связь с Alter и маршрутизация команд.

Пример команды между Pi и контроллером:

```json
{"device":"head_controller","action":"move","pan":20,"tilt":-5}
```

Сервоприводы и моторы питаются отдельно, не от GPIO Raspberry Pi.

## Этапы

1. Кнопка → запись голоса → Alter API → TTS → динамик.
2. Приём файлов через локальную web-страницу.
3. Wake word «Альтер».
4. Экран/глаза и световая индикация.
5. ESP32 и поворот головы.
6. Камера и датчики.
7. Колёса, моторы и корпус.

Клиентское приложение можно писать на Python в PyCharm и запускать на Pi как systemd-сервис.

## Безопасность

- Не хранить API-ключи в устройстве.
- Использовать отдельный ограниченный токен устройства.
- Не открывать Raspberry Pi напрямую в интернет.
- Принимать команды только по HTTPS.
